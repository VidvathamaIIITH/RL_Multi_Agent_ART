Your single launcher script
I created one launcher (in both project copies) that starts the complete connected app — the web UI and the API/agents/images run together in one process on one port, so the frontend and backend are always connected (no separate ports, no CORS, no proxy 404s).

File	Use
launch.sh	On the Azure VM (Linux) — this is the one you run
launch.ps1	On Windows, for local testing
Both are in Perfect_Chatbot/canvasmind/ and Perfect_Chatbot/RL_Multi_Agent_ART/canvasmind/ (the copy your VM uses).

How to run it on the VM — once, start to finish

cd ~/canvasmind                         # or RL_Multi_Agent_ART/canvasmind
chmod +x launch.sh                      # first time only

# Make sure Azure creds are available (usually already exported on the GPU VM):
echo "$AZURE_OPENAI_API_KEY"            # if empty, export it:
# export AZURE_OPENAI_API_KEY="your-key"
# export AZURE_OPENAI_ENDPOINT="https://your-resource.openai.azure.com/"

./launch.sh                             # ← launches EVERYTHING on port 8000
What launch.sh does automatically:

Checks/notifies about Azure credentials
Detects dependencies; if missing, creates a venv and installs them
Launches the full app (frontend + backend connected) on port 8000
Then open in your browser:


https://rniazure.tcsapps.com/dev-workspaces/<your-workspace>/proxy/8000/
Type a prompt → Start Session → watch ARIA and NEXUS converse, JUDGE score each round, and the canvas images appear — all live.

Want a different port (e.g. one already in the proxy list)? ./launch.sh 3000 then open …/proxy/3000/.

The only thing that must be real is the Azure credentials — everything else is verified working end-to-end.
